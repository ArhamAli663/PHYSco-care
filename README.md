**AR Physco Care** (AR Physio Care Gujranwala) is a modern, full-stack Web Application built for **Dr. Abdul Rouf's Physical Therapy & Rehabilitation Clinic** in Satellite Town, Gujranwala, Pakistan.

🌐 **Live Website**: [https://dr-abdul-rouf-physio.web.app](https://dr-abdul-rouf-physio.web.app)

---

## ✨ Features & Modules

### 🌐 Public Clinic Web Portal
- **Hero & Clinic Highlights**: Showcasing clinical specializations in musculoskeletal pain, joint therapy, sports injuries, and neurological rehabilitation.
- **Service Listings & Fee Details**: Transparent 1,000 RS session fee structure and daily consultation hours (4:00 PM – 10:00 PM).
- **Google Maps Integration**: Direct navigation to Block B Satellite Town, Gujranwala clinic location.

### 📅 Patient Appointment System
- **Interactive Booking Form**: Patients can choose preferred dates, time slots, and specify health conditions.
- **Live Status Tracker**: Patients get real-time visual banners for `Pending`, `Approved`, `Completed`, or `Cancelled` appointment updates.

### 💬 Patient Questions & Answers (Q&A)
- **Direct Health Consultation**: Patients can submit health questions directly to Dr. Abdul Rouf.
- **Public & Private Q&A Board**: Shows patient questions alongside Dr. Rouf's official answers.

### 👨‍⚕️ Doctor / Admin Management Portal
- **Protected View**: Dedicated login dashboard for Dr. Abdul Rouf.
- **Patient Appointment Management**: Approve, complete, or cancel appointments with one click.
- **Responsive Q&A Response Desk**: Doctor can review patient questions and post official replies.
- **Real-Time Clinic Metrics**: Tracks total bookings, pending approvals, and unanswered health questions.

### 📱 100% Responsive Design System
- Built with a custom CSS design system optimized for smartphones, tablets, and desktop screens with touch-scrollable tables and tab controls.

## 🚀 Local Setup & Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/ArhamAli663/PHYSco-care.git
   cd PHYSco-care
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```
